SQL - Lenguaje de consulta estructurada

¿Qué es SQL?

SQL es un lenguaje que se utiliza para crear, organizar, consultar y modificar bases de datos.

¿Para qué sirve?

- Guardar información.
- Consultar datos.
- Agregar nuevos registros.
- Modificar información.
- Eliminar datos.

Comandos principales de SQL

Comando| Función
SELECT| Consultar datos
INSERT| Agregar datos
UPDATE| Modificar datos
DELETE| Eliminar datos
CREATE| Crear tablas
DROP| Eliminar tablas

Ejemplo de SQL

CREATE TABLE alumnos (
    id INT,
    nombre VARCHAR(50),
    edad INT
);

INSERT INTO alumnos
VALUES (1, 'Pablo', 17);

SELECT * FROM alumnos;

Ventajas de SQL

- Es fácil de aprender.
- Organiza grandes cantidades de información.
- Permite buscar datos rápidamente.
- Se utiliza en muchas empresas.

Conclusión

SQL es una herramienta importante para trabajar con bases de datos, ya que permite guardar, organizar y consultar información de manera sencilla.
